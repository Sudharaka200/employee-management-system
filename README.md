
# Employee Management System

## Introduction

A simple Employee Management System where you can add, update, view, and delete employee records. It uses a MySQL database to store employee details.

## Features

* Add new employees
* Update employee details
* Delete employee records
* View employee list

## Requirements

* PHP
* MySQL 
* local server (e.g., XAMPP, WAMP)

## Installation
1.Clone the repository:

        git clone https://github.com/Sudharaka200/employee-management-system

2.Set Up the Database:

* Open your MySQL client (like phpMyAdmin or MySQL Workbench).
* Create a new database (e.g., employee_management).
* Import the employee.sql file into the newly created database

## Run the Application

    1.Make sure you have a local server setup (e.g., XAMPP or WAMP).

    2.Place the project files in the htdocs folder (for XAMPP) or the equivalent directory for your local server.

    3.Start the local server and navigate to the application in your browser (e.g., http://localhost/employee-management-system).

    4.Access the application and start managing employees!
